# GlowLedger

GlowLedger is a free, independent beauty-spending calculator.

## Features
- Add skincare, makeup, haircare and other products
- Estimate monthly and annual spending based on replacement frequency
- Review repeated product categories
- Save entries in your own browser (localStorage)
- Export your product list as CSV
- No login, server, cookies or payment integration required

## Hosting
Publish with GitHub Pages using Settings → Pages → Deploy from a branch → main → /(root) → Save. The expected URL is https://gatorredsox.github.io/glowledger/ **only after GitHub Pages reports successful deployment**.

## Privacy
Product entries are saved in browser local storage. They are not uploaded to our server. GitHub Pages hosting may collect operational logs under GitHub's own policies. This app currently has no affiliate links or analytics.

## Revenue
Amazon Associates account exists under the owner's separate RetireDividend website. Do not publish affiliate links until the GlowLedger property and any social profiles are properly registered and disclosures are added. Never publish tracking IDs or credentials in repository code.

## Project separation
GlowLedger is independent of RetireDividend. No shared production services, user data, domains or deployment credentials.

## Important
This tool estimates spending, not skincare suitability, diagnosis or treatment. A repeated category is not proof that a product is redundant.
